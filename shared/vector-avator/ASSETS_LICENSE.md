# 見本キャラ「仮うさぎ」の素材について

## 対象

このリポジトリに含まれる、見本キャラ「仮うさぎ」（キャラ ID `usagi`）の次の素材です。

- `inputs/kariusagi/` の元の絵とキャラクターシート
- `public/characters/usagi/vector/` の部品（`vector.json`）と参照画像（`ref/`）
- `tools/vector/sheets/characters/usagi.*`、`tools/vector/sheets/h3/usagi.txt` のキャラの説明
