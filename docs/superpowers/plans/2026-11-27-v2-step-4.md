- Files: `shared/scene.ts`, `server/scene.ts`, `server/index.ts`, `src/steps/VoiceoverStep.tsx`, `src/steps/AnimateStep.tsx`, `shared/direction.ts`, tests for speech, scene building, and UI.

## Required sequence

Each task gets failing tests first, implementation, full Vitest and TypeScript before its commit, then a fresh read-only review and a fix/recheck pass. If subagents are unavailable, review each task in a fresh session that reads only that task's diff, plan, and shared rules; record this fallback explicitly in the report. No Director, transitions, props, walking, new actions, or other providers.
