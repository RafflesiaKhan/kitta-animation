# From reference to design

Describe the character so every later drawing stays consistent:

- **Identity**: name if obvious, age/role impression, personality in two words.
- **Silhouette and proportions**: head-to-body ratio (cartoons are often 1:2.5–1:3), body build (slim, round, broad),
  head shape, limb thickness. Give numbers on Kitta's canvas: the figure stands on y≈950, hips (waist) y≈560–640,
  head top y≈30–80, centred on x=500.
- **Palette**: skin/fur, hair, each garment, accessories, outline colour (hex).
- **Face**: eye style (sclera + pupil, dot eyes…), brows, nose, mouth, facial hair, ears, glasses.
- **Costume and props worn**: which side each asymmetric item is on (screen side as seen in the front view).
- **symmetric**: true when mirroring the left-facing views gives correct right-facing ones (no side-specific items).
- **Inferred**: what the reference does not show (legs, back, far side) and what you assumed.

Style target: crisp TV-cartoon look — flat fills, bold dark outlines (stroke width 6–9), simple readable shapes,
expressive eyes with white sclera and dark pupils, a mouth drawn as a separate shape so it can change.
